설정

GPT 계정 초기화에 필요한 인증 정보를 설정합니다. 설정은 로컬 PC에만 저장됩니다.

ℹ️
이 설정은 계정 초기화 기능에만 필요합니다. 멤버 추가 기능은 별도 설정 없이 사용 가능합니다.
인증 정보
모든 GPT 계정의 인증 코드가 전달되는 이메일 주소입니다.
아래 가이드를 참고하여 Gmail 앱 비밀번호를 생성하세요.
gpt1~gpt30 계정에 공통으로 설정된 비밀번호입니다.
📋 Gmail 앱 비밀번호 생성 가이드
1
2단계 인증 활성화 (이미 되어있다면 건너뛰기)

Google 계정 보안 페이지 접속 → "2단계 인증" 클릭 → 안내에 따라 활성화

⚠️ 2단계 인증이 켜져 있어야만 앱 비밀번호를 생성할 수 있습니다.
2
앱 비밀번호 페이지 접속

https://myaccount.google.com/apppasswords 접속

또는: Google 계정 → 보안 → "Google에 로그인" 섹션 → "앱 비밀번호"
3
앱 비밀번호 생성

앱 이름에 "GPT자동화" 입력 → "만들기" 클릭

4
16자리 비밀번호 복사

화면에 표시된 16자리 비밀번호를 복사합니다. (예: abcd efgh ijkl mnop)

⚠️ 이 창을 닫으면 다시 볼 수 없습니다! 반드시 복사해주세요.
5
위 "앱 비밀번호" 칸에 입력

복사한 16자리를 띄어쓰기 없이 위 입력칸에 붙여넣으세요. (예: abcdefghijklmnop)

# 에이블런 GPT 계정 추가 — Chrome 확장 프로그램

> Google Groups에 멤버를 **엑셀 복사 → 붙여넣기** 한 번으로 자동 등록해주는 업무 자동화 도구입니다.

---

## 📌 이 도구는 무엇인가요?

에이블런에서 GPT 계정(gpt1@ablearn.kr ~ gpt30@ablearn.kr)을 사용자에게 배정할 때,  
해당 Google 그룹에 사용자 이메일을 일일이 수동으로 추가해야 합니다.

**기존 방식 (수동)**:
1. 주소창에 `https://groups.google.com/a/ablearn.kr/g/gpt10/members` 입력
2. "회원 추가" 버튼 클릭
3. 이메일 입력 → 확인
4. gpt1 ~ gpt30 까지 **계정마다 반복** 😩

**이 확장 프로그램 사용 시**:
1. 엑셀에 이메일과 GPT 계정번호 입력
2. 복사 → 확장 프로그램에 붙여넣기
3. "자동 추가 시작" 클릭 → **끝!** 🎉

---

## 🚀 사용 방법 (3단계)

### STEP 0. 사전 준비

- ✅ Chrome 브라우저에 확장 프로그램이 설치되어 있어야 합니다.
- ✅ **Google Workspace 관리자 계정**으로 Chrome에 로그인되어 있어야 합니다.
- ✅ `groups.google.com` 에 접속이 가능한 상태여야 합니다.

### STEP 1. 엑셀/구글 스프레드시트에 데이터 준비

아래 형식에 맞춰 **두 열**에 데이터를 입력합니다:

| A열: 등록할 이메일        | B열: 할당할 GPT 계정 |
|--------------------------|---------------------|
| hong@example.com         | gpt1                |
| kim@example.com          | gpt5                |
| lee@example.com          | gpt10               |

> **💡 GPT 계정 입력 Tip**
> - `gpt10` 처럼 **숫자만** 써도 OK
> - `gpt10@ablearn.kr` 처럼 **전체 이메일**로 써도 OK
> - 자동으로 `gpt10` 부분만 인식합니다!

### STEP 2. 복사 → 확장 프로그램에 붙여넣기

1. 엑셀에서 A열 + B열을 **드래그하여 복사** (`Ctrl+C`)
2. Chrome 우측 상단의 확장 프로그램 아이콘 🧩 클릭
3. **"에이블런 GPT 계정 추가"** 클릭하여 팝업 열기
4. **Step 1 영역의 빈 칸**을 클릭한 후 **붙여넣기** (`Ctrl+V`)
5. 아래 **Step 2 표**에 데이터가 자동으로 채워지는지 확인

### STEP 3. 자동 추가 실행

1. 표에 데이터가 올바르게 채워졌는지 확인
2. **"▶ 순차적 자동 추가 시작"** 버튼 클릭
3. 자동으로 탭이 열리면서 한 명씩 순서대로 등록됩니다
4. 모든 작업이 끝나면 **"🎉 모든 작업이 끝났습니다!"** 메시지가 표시됩니다

> ⚠️ **주의사항**
> - 실행 중에는 **자동으로 열리는 탭을 닫지 마세요**. 작업이 중단됩니다.
> - 실행 중에 다른 탭에서 작업해도 괜찮지만, 확장 프로그램 팝업은 열린 상태를 유지하세요.
> - 한 명당 약 5~8초 정도 소요됩니다.

## 🔧 개발자용: 업데이트 배포 방법

이미 Chrome 웹스토어에 배포된 상태에서, 코드를 수정한 후 업데이트를 배포하는 방법입니다.

### 1. 버전 번호 올리기

`manifest.json` 파일에서 `"version"` 값을 올립니다:

```json
// 변경 전
"version": "1.0"

// 변경 후 (예시)
"version": "1.1"
```

> ⚠️ **버전을 올리지 않으면 웹스토어에서 업로드가 거부됩니다!**

### 2. 확장 프로그램 파일을 ZIP으로 압축

`chrome_extension` 폴더 안의 파일들만 선택하여 ZIP 파일로 압축합니다:

```
chrome_extension/
├── manifest.json
├── popup.html
├── popup.js
├── background.js
├── content.js
└── icon.png
```

**Mac에서 압축하기:**
```bash
cd chrome_extension
zip -r ../에이블런_GPT_계정추가_v1.1.zip . -x ".*" -x "__MACOSX"
```

**Windows에서 압축하기:**
- 폴더 안의 모든 파일 선택 → 우클릭 → "ZIP 파일로 압축"

> ⚠️ `chrome_extension` **폴더 자체**를 압축하지 말고, **폴더 안의 파일들**을 압축하세요.  
> ZIP을 열었을 때 바로 `manifest.json`이 보여야 합니다.

### 3. Chrome 웹스토어 개발자 대시보드에 업로드

1. [Chrome 웹스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole) 접속
2. **"에이블런 GPT 계정 추가"** 항목 클릭
3. 좌측 메뉴에서 **"패키지"** 선택
4. **"새 패키지 업로드"** 클릭 → ZIP 파일 선택
5. 업로드 완료 후 **"제출하여 검토 요청"** 클릭

> 검토에는 보통 **1~3일** 정도 소요됩니다.  
> 내부 배포(비공개)인 경우 더 빠를 수 있습니다.

### 4. (선택) 설명/스크린샷 업데이트

웹스토어 대시보드 → **"스토어 등록정보"** 에서 아래 항목을 수정할 수 있습니다:
- 상세 설명
- 스크린샷 (1280×800 또는 640×400)
- 아이콘 (128×128)

## ❓ FAQ (자주 묻는 질문)

**Q. "회원 추가" 버튼을 못 찾는다는 오류가 나요.**  
A. Google Workspace **관리자** 계정으로 로그인되어 있는지 확인하세요. 일반 계정은 멤버 추가 권한이 없습니다.

**Q. 중간에 실패한 사람이 있으면 어떡하나요?**  
A. 이미 등록된 사람은 건너뛰어지므로, 실패한 항목만 다시 입력하여 재실행하면 됩니다.

**Q. 한 번에 최대 몇 명까지 등록 가능한가요?**  
A. 기술적 제한은 없지만, 안정적인 동작을 위해 **30명 이하**를 권장합니다.

**Q. GPT 계정은 gpt1~gpt30 외에 다른 것도 가능한가요?**  
A. B열에 입력한 값이 Google Groups URL의 그룹 이름이 됩니다. 해당 그룹이 존재하고 권한이 있다면 다른 그룹도 가능합니다.
